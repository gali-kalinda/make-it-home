# Make It Home 1.0.0 发布验收

日期：2026-10-23。实际环境：Windows、Node.js v24.18.0、Chrome。macOS / Linux 启动入口和本机密钥保存已实现；本机没有实际运行这两种操作系统。仓库 CI 配置 Windows / Ubuntu + Node.js 22，需上传后由 GitHub 执行，不能将配置文件视作已通过的云端结果。

## 已实际完成

- 在独立发布目录执行 `npm ci --no-audit --no-fund`，从锁文件成功安装依赖。
- 使用正式启动器 `node scripts/start.cjs` 启动本机 8792 端口，未复用工作目录的 `.local` 或个人密钥。
- 38 组测试全部通过：几何、墙体、门窗、材质、模型配置、三视图确认、历史备份、库去重、流式 HTTP、跨站保护、本机加密与 OCR 文件路由等。
- 浏览器首次打开为无墙体、无家具的空白项目，首页可见上传、新建、案例查看。
- 从案例查看载入指定方案：12 段墙体、3 个房间、26 件家具、5 个自定义模型资源；面积约 35.42㎡。
- 2D 和 3D 均实际显示此案例。3D 场景检查为 26 个家具对象、3 个房间，地面材质正常。
- 点击新建后，墙体和家具归零、原图为空；历史方案新增 26 件家具的“新建前备份”。
- 刷新后空白状态仍保留；重新载入案例、再次刷新后，3 个房间和 26 件家具仍保留。
- 案例查看没有发起识别、生图或建模 API 请求。两类 AI 设置均为 `hasKey:false / configured:false`。
- 私密设置路径和直接访问 node_modules 返回 404；指定 OCR WASM / 训练数据由已安装 npm 包提供，返回 200 和正确 MIME。
- 移除了启动时读取私人参考照片的旧依赖，以及依赖当前维护者机器路径的 sharp 回退。

## 发布边界

此轮验收针对可分发、启动和内置案例体验。模型服务兼容测试使用模拟 API，不是对所有第三方账号、模型权限和生图质量的保证。AI 识别和模型结果需要使用者自行核对。

压缩包不含 API 密钥、`.local`、浏览器历史、node_modules、CubiCasa5K 权重、Python 推理包、私人原图和测试输出。内置 GLB 中仅保留案例需要的程序化纹理与近似模型。
