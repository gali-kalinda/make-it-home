# Make It Home 1.0.1 启动修复

修复 `EADDRINUSE` 导致双击启动后退出的问题。

- 优先监听指定端口，冲突时自动尝试后续 19 个端口。
- 重复启动同一安装目录时，验证服务身份后复用，打开实际地址。
- 不终止占用端口的其他程序，不复用其他安装目录。
- 浏览器只在服务就绪后打开；设置接口使用实际监听端口验证同源请求。
- 地址始终打印在终端；自动打开失败时可复制访问。

2026-10-25：已在 Windows / Node.js 24.18.0 上实际验证端口占用、重复启动、不同安装目录、并发监听、错误端口配置以及换端口后的网页与设置接口。完整测试结果见随附验收记录。

本机完整测试：39 组全部通过，发布文件检查通过。
